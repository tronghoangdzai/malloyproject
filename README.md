# 🚗 Used Car Price Analysis with Malloy

## Overview
This project explores a large dataset of used car listings (400,000+ rows) from Craigslist across the United States. Using the **Malloy** language for data exploration and DuckDB for querying, I investigated how different factors—like **brand**, **mileage**, and **vehicle condition**—impact the **price** of used cars.

## Dataset
- Source: [Kaggle - Craigslist Vehicle Listings](https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data)
- File: `vehicles.csv`
- Size: ~400,000 rows, 25 columns

## Key Questions Explored
- Which car brands have the highest average resale prices?
- How does the year of the vehicle affect its resale value?
- Which U.S. states have the most expensive used cars on average?
- How does vehicle condition impact resale price?
- Which fuel types (gas, diesel, hybrid, electric) are priced higher?
